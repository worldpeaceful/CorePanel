# 机核仪表便携版

1. 将 ZIP 完整解压，保留解压得到的整个文件夹。
2. 在 Windows x64 上双击“机核仪表.exe”。便携版已包含 .NET 桌面运行时。
3. 右键仪表可打开设置、切换皮肤、调整尺寸和配置开机自启动。

部分温度读数需要硬件支持。请先在“设置 → 传感器状态”查看原因。若需要 PawnIO，可从 [官方发布页](https://github.com/namazso/PawnIO.Setup/releases/tag/2.2.0) 单独下载，安装后再从右键菜单以管理员身份运行。

已启用开机自启动时，移动应用前先关闭该选项，移动后从新目录启动并重新开启。
